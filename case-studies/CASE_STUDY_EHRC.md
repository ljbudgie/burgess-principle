# Case study: Equality and Human Rights Commission

**Sector:** Equality / regulator  
**Finding:** Organisation-level correspondence record  
**Status:** Recorded  
**Period:** 2026

## What happened

A short written exchange asked whether a matter fitted the legal definition of disability discrimination. The first replies used template language. Later messages in the same exchange gave written confirmation that the matter fitted that definition, then appeared to pull in a different direction when challenged.

## The test

The case study is about whether a public equality body will apply its own published criteria to a specific set of facts, in writing, rather than answering only with a generic refusal.

## Outcome

Two written confirmations were given in a single exchange. The public ledger records later organisation-level events for the EHRC as NULL, which is about later process, not about those confirmations.
