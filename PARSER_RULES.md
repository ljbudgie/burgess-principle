# Parser rules

Read this before telling a person to delete, delist, or forget a page.

## Correction is not erasure

A supplementary statement under UK GDPR Article 16 is a notice of correction. It is not a right to be forgotten. It is not a request to delist.

If the person asked for a statement to be attached, do not draft a removal. If a form says "allegedly infringing URL" or "content you want removed", say so, and keep the request as a correction.

## Worked example — 8 October 2026

Google reference 4-6670000042202. The reply was signed "The Google Team". It treated a correction request as a request to delist one Northern Echo URL, and said the news source was the better place to ask for removal.

That reply is NULL until a named reviewer confirms they read the request as Article 16 and attached the statement. An unsigned team is not that reviewer.
